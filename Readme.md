# 🍎 Apple Store - Landing Page Futurista

Este projeto é uma **Landing Page imersiva** para uma loja de tecnologia, desenvolvida para destacar produtos premium através de um carrossel dinâmico e uma interface visualmente impactante. O foco principal é a experiência do utilizador (UX) através de animações fluidas e um design moderno.

---

## 🚀 Funcionalidades

* **Slider Interativo:** Navegação entre produtos com transições suaves e efeitos de profundidade.
* **Animações de Entrada:** Títulos, descrições e imagens possuem animações sincronizadas que ocorrem toda vez que um item é selecionado.
* **Autoplay Dinâmico:** O catálogo de produtos alterna automaticamente a cada 5 segundos para manter o engajamento visual.
* **Indicadores de Progresso:** Contador numérico e barras visuais (*dots*) que mostram a posição atual da navegação.
* **Design Futurista:** Uso de fontes tecnológicas (**Orbitron**), sombras neon e fundos com gradientes e partículas animadas.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização avançada, animações com `@keyframes`, filtros de imagem (`drop-shadow`) e layout responsivo.
* **JavaScript (Vanilla):** Lógica de controlo do slider, manipulação de classes do DOM e gestão de temporizadores.
* **Google Fonts:** Tipografia personalizada utilizando as fontes *Montserrat* e *Orbitron*.

---

## 📦 Como Executar o Projeto

1. Clone este repositório para a sua máquina local.
2. Certifique-se de que a estrutura de pastas contém as imagens necessárias no diretório `img/` (ex: `apple-watch.png`, `air-pods.png`, `vision-pro.png`).
3. Abra o arquivo `index.html` em qualquer navegador moderno.

---

## 📄 Estrutura de Arquivos

* `index.html`: Contém a estrutura principal e os dados dos produtos.
* `style.css`: Responsável por todo o visual e animações de entrada e saída.
* `script.js`: Gere a lógica de troca de itens e o cronómetro do carrossel.
